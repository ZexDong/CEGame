# Unfinished starter

This is an independent native UE 5.7.4 project. Its default entry displays a health
screen and writes an honest `not_ready` observation. No game board, placed defenses,
waves, enemy AI, economy, upgrade system, or completed game is supplied.

Content contains individual presentation assets and their dependencies. Assemble the
game described by the parent GDD. The source files and map organization are editable.
The normal game entry is resolved from Config/DefaultEngine.ini.
