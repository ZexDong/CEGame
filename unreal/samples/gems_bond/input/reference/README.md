# Visual references

The three supplied frames show the opening, placement UI and crowded early combat.
They illustrate the scene composition, vegetation layers, elevated camera, pink crystal,
bright grass, brown clearing, sidebar styling and in-world feedback described in GDD
Section 6. Their native resolution is 1920 x 1080. The written requirements are complete;
the frames add no implicit requirements or pixel-by-pixel matching target.

The displayed counters, placement positions and instructional UI are examples. GDD Section 6
defines the required board, rules, controls, timing and lifecycle. Build the 3D scene using
the mandatory visual assets already in starter-project/Content/. These PNGs are documentation,
not runtime art to import or use as a gameplay background. Legal provenance is in assets/legal/.
