# Source-corroborated evidence review

Use the checkpoint catalog and evidence from one bound candidate. Source review
supplements the runtime collector; complete journeys require runtime evidence
from those journeys.

Inspect complete input bindings, implementation paths, state guards, engine
semantics, referenced assets and contemporaneous runtime evidence. Cite complete
relevant function bodies with file hashes and line excerpts. A name, declared
asset role or final counter is not evidence that a behavior ran. Source intent
cannot override contradictory runtime observations.

Use Invoke-ActionRoguelikeCanonicalScorer.ps1 -EvidenceReviewPath with the
candidate/run/catalog identity, exact checkpoint coverage, source hashes,
excerpts, runtime artifact hashes and concrete reasons. Keep every cited path
inside the corresponding isolated candidate or evidence directory.
