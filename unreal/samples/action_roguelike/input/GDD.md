# Rift Hunting: Timed Survival Arena Vertical Slice

## 1. One-Sentence Task

The player controls a third-person character presented with the character models and action animations provided with the project, moving, jumping, dashing, fighting, obtaining the Teleport Ability, collecting Credits, and purchasing healing while surrounded by similar enemies represented with the character models and action animations provided with the project; victory is achieved by surviving until the target time limit, and failure occurs if Health reaches zero (PLAYER-CONTROL-01..PLAYER-CONTROL-18, PRESENTATION-01..PRESENTATION-27, COMBAT-01..COMBAT-25, ATTRIBUTE-01..ATTRIBUTE-10, RESOURCE-01..RESOURCE-12, AI-01..AI-15, SURVIVAL-01..SURVIVAL-16, ENDGAME-01..ENDGAME-23, UI-01..UI-05, LIFECYCLE-01..LIFECYCLE-32).

## 4. Player Goal and Complete Flow

### 4.1 Player Goal

Players use movement, jumping, dashing, Magic Projectiles, and Black Hole to handle enemies that change attack patterns, observe character models, action animations, and object models provided with the project as they change with the current state, obtain the Teleport Ability Pickup to add Projectile Teleport, and use Credits and Health Potions to maintain survival, aiming to reach the survival endpoint (PLAYER-CONTROL-10..PLAYER-CONTROL-18, PRESENTATION-01..PRESENTATION-27, COMBAT-01..COMBAT-25, RESOURCE-01..RESOURCE-12, AI-01..AI-15, SURVIVAL-01..SURVIVAL-16, ENDGAME-02..ENDGAME-23).

### 4.2 Complete Player Flow

Enter the Game
→ [PLAYER-CONTROL-01..PLAYER-CONTROL-18, PRESENTATION-01, PRESENTATION-03..PRESENTATION-08, SURVIVAL-01..SURVIVAL-03, ENDGAME-01] Control the character, observe corresponding actions, and begin survival
→ [COMBAT-09..COMBAT-11, PRESENTATION-23] Find and pick up the Teleport Ability Pickup
→ [COMBAT-01..COMBAT-08, COMBAT-12..COMBAT-25, AI-01..AI-15, PRESENTATION-02, PRESENTATION-09..PRESENTATION-19, PRESENTATION-22, PRESENTATION-24..PRESENTATION-27] Adjust distance, activate abilities, and respond to enemy pattern changes
→ [RESOURCE-01..RESOURCE-12, PRESENTATION-20, PRESENTATION-21] Pick up Credits and attempt healing according to battle situation
→ [SURVIVAL-02..SURVIVAL-16, UI-01..UI-05] Monitor survival progress and respond to subsequent respawns
→ [ENDGAME-02..ENDGAME-23] Achieve victory or enter defeat
→ [LIFECYCLE-01..LIFECYCLE-32] Restart or Reopen

### 4.3 Core Loop

[PLAYER-CONTROL-02..PLAYER-CONTROL-18, PRESENTATION-01, PRESENTATION-03..PRESENTATION-08, UI-01..UI-05] Observe status and adjust position using movement, jump, and dash
→ [COMBAT-09..COMBAT-11, PRESENTATION-23] Search for items before acquiring the Teleport Ability
→ [COMBAT-01..COMBAT-08, COMBAT-12..COMBAT-25, PRESENTATION-09..PRESENTATION-11, PRESENTATION-22, PRESENTATION-24..PRESENTATION-27] Select and use the currently available ability
→ [AI-01..AI-15, ATTRIBUTE-03..ATTRIBUTE-10, PRESENTATION-02, PRESENTATION-12..PRESENTATION-19] Enemy switches mode and counterattacks, both sides' status changes
→ [RESOURCE-01..RESOURCE-12, PRESENTATION-20, PRESENTATION-21] Obtain Credits or attempt to recover Health
→ [SURVIVAL-02..SURVIVAL-16, ENDGAME-02..ENDGAME-23] Continue to respond to refresh, or enter the already determined outcome of the current round

## 6. Numbered Requirements: Sole Acceptance Authority

### 6.1 Requirement Splitting Rule

Each requirement describes one player result that can fail independently and is worth judging independently. Exact quantities, values, timing, order, text, and format affect acceptance only when a numbered row below states them.
