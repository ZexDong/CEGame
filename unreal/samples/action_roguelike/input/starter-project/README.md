# Arena Slice Answer-Free Common Start

This is an Unreal Engine 5.6.1 Content-only Blank project. It contains a static arena plus unassembled models, animations, materials, textures, skeletons, and physics assets. It has no game module or implemented gameplay.

Open `ArenaSlice.uproject`. The configured default map is `/Game/Arena/Maps/StarterArena`.

The start contains no `Source/`, gameplay Blueprint, Anim Blueprint, Niagara system, AI, UI, input asset, save asset, wave logic, or win/loss flow. The supplied assets are source material. Required player-visible results are defined only by `../GDD.md` Section 6, and exact supplied asset paths are listed in `../ASSET_CATALOG.md`.
