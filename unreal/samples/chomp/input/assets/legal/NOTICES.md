# Resource-use terms

The supplied meshes, textures, vector icon, materials, starter code and documents are supplied for use, modification and incorporation into benchmark implementations. Editable OBJ, PNG and SVG copies are included for offline work. This permission applies to these supplied resources; Unreal Engine and third-party trademarks retain their separate terms. GDD ASSET-01..05 defines the required art usage for this task.

The maze diagram supplies declarative design cells and player requirements. Static presentation resources contain no assembled level, character behavior, AI or gameplay implementation.

Unreal Engine and its built-in resources remain subject to the license accepted for the installed engine. Engine primitives and default fonts are referenced from that installation and are not copied into this package. The interface catalog supplies API/symbol metadata rather than engine implementation bodies and does not license the engine itself.

The project adds no third-party runtime library. `ASSET_LICENSE_MAP.json` maps every supplied art resource and source copy to these terms.
