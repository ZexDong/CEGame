# Bomber Local Duel Starter Project

Open `BomberStarter.uproject` with Unreal Engine 5.7.4.

This source-only starter intentionally contains no duel gameplay. It contains only:

- a stable English health screen;
- a read-only engine/task-state bridge whose gameplay provider is not ready;
- the fixed public 11x9 layout data;
- the original Bomber bomb and local-player marker assets; and
- a content-only `BlockoutMap` plugin containing clean character, arena, and three power-up assets with no gameplay module or Blueprint.

All generated directories must remain outside the public release.
