# Unreal benchmark tool contract

The versioned executor and observer implement process start/stop/reopen, held and pressed keyboard input, pointer input, read-only state, waits and client capture. Engine identity and operation results are checked at runtime. No previous machine validation receipt certifies the current host. Use the public smoke in a fresh external run to measure build, first frame, observation, capture, reopen and cleanup. Input leases must be released on every exit.
