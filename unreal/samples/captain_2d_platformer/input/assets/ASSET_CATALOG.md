# Public Asset Catalog

Every required file is listed below. Import and assemble it inside `starter-project/`; keep source files unchanged. `assets/ASSET_CATALOG.json` records hashes, dimensions, dependencies and source animation timing. Timing describes the supplied art, without prescribing an animation implementation.

The room geometry and decoration placement are fixed by `GDD.md` Section 6. The art preview contains no live actors. The room reference is a composition design illustration with the captain, pig and traversal objects. GDD ENEMY-01 defines the patrol corridor by its physical boundaries.
