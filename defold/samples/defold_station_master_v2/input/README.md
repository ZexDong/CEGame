# Station Master: Emergency Expansion Shift — public input

This directory is the complete public starting point for the task. Develop only inside
`starter_project/`; it is intentionally buildable but contains no target management gameplay.

Read:

1. `GDD.md` — the task-specific player requirements and published Dashboard names;
2. `COMMON_BASELINE.md` — the game-independent quality requirements;
3. `DASHBOARD_SPEC.md` — the shared read-only state format;
4. `naming-tables.json` — the exact Station-specific slot, entity, target, and control names;
5. `DEFOLD_ENGINE_INTERFACE_GUIDE.md` — verified Defold 1.13.0 engineering interfaces;
6. `TOOLCHAIN.md` — this task's project entry, normal pointer input, and Dashboard transport;
7. `reference_images/README.md` and `legal/UPSTREAM_MIT_LICENSE.txt` — reference provenance and
   permitted use.

The GDD and Common Baseline define what to build. The remaining documents only define public tools
and observation interfaces. The Dashboard reports state and has no input, reset, purchase, resource,
time, or result-forcing operation.

Reference screenshots are design references, not an importable asset pack. This input contains no
Gold source, private checkpoint script, score weights, evaluator, answer path, or historical result.
