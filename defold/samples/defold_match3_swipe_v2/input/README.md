# Match 3 Swipe: Three-Chapter Cascade Challenge

Implement the campaign in `starter_project/`. The project contains buildable
scaffolding and the Dashboard transport. The game design is in `GDD.md`;
`LEVEL_SPEC.md`, `campaign.json` and `CAMPAIGN_RULES.md` define chapter data,
mechanics, progression and persistence.

Use `DEFOLD_ENGINE_INTERFACE_GUIDE.md` for tools, `RUNNING.md` for build and
launch commands, and `TOOLCHAIN.md` for task-specific paths.
The public read-only observation contract is specified by `DASHBOARD_SPEC.md`,
`DASHBOARD_REQUIREMENTS.md`, `naming-tables.json` and the corresponding schemas.
Run `tools/dashboard_self_check.py` against a real emitted trace.
Available materials and their sources are listed in `assets/ASSET_MANIFEST.md`.
