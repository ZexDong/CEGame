# Third-Person Island Delivery — public input

This directory is the complete public starting point for the task. Develop only inside
`starter_project/`; it is intentionally buildable but contains no target island or delivery
gameplay.

Read:

1. `GDD.md` — the task-specific player requirements and published Dashboard mapping;
2. `COMMON_BASELINE.md` — the game-independent quality requirements;
3. `DASHBOARD_SPEC.md` — the shared read-only state contract;
4. `naming-tables.json` — the exact public slots, entity kinds/states, target kinds, coordinates,
   and controls for this task;
5. `dashboard-snapshot.schema.json` and `naming-tables.schema.json` — the two public schemas;
6. `DEFOLD_ENGINE_INTERFACE_GUIDE.md` — verified Defold engineering interfaces;
7. `TOOLCHAIN.md` — the project entry, normal player input, and Dashboard transport;
8. `reference_images/README.md` and `legal/UPSTREAM_MIT_LICENSE.txt` — reference provenance and
   permitted use.

The GDD and Common Baseline define what to build. The remaining documents define public tools and
observation interfaces only. The Dashboard has no movement, pickup, delivery, timer, restart, or
result-forcing operation.

The reference screenshots are design references, not an importable Gold asset pack. This input
contains no Gold source, private checkpoint script, scoring weights, answer route, or historical
result.
