This directory is the single canonical model-visible Input for the complete car-platforming reconstruction.

| Path | Purpose |
|---|---|

| `GDD-en.md` | Story, Endless, Hill Climb, Garage, settings, trophy, and persistence contract |
| `TOOLCHAIN-en.md` | Engine, input, save path, procedural material, dashboard, and verification |
| `BENCHMARK_MANIFEST.json` | Path and entry index |
| `sp/` | Answer-empty Godot starter with dashboard skeleton |
| `Assets/` | Procedural role catalog, coverage, manifest, and contact sheet |
| `legal/` | Source-license boundary; no upstream branded media is distributed |

The upstream repository has no redistribution license, so its code, logo, audio, and scenes are not copied here. The task is reconstructed from player-visible mechanics with runtime-drawn presentation.
