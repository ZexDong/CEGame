# MataroDrive Input License Status

The upstream repository does not contain an explicit open-source or redistribution license. Therefore no upstream code, logo, audio, scene, resource, font, or derived bitmap is copied into the model-visible `input/` package.

The public task distributes only:

- independently written benchmark documents and JSON contracts;
- the generic Godot dashboard skeleton;
- an independently created procedural-role contact sheet and its SVG source.

The game is reconstructed from player-visible mechanics with runtime-drawn presentation. Implementers must not fetch or reconstruct upstream branded media. The supplied documents, contracts and procedural starter are benchmark-authored materials covered by the package LICENSE.
