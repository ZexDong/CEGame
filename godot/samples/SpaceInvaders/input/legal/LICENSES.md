# SpaceInvaders Input License Status

The upstream repository includes the MIT license reproduced in `LICENSE`. Its README states that the original images and sounds were created by the repository author. The public Input distributes only those mapped image, audio, and icon files and preserves the upstream license and credits.

`PixeloidMono-d94EV.ttf` is intentionally excluded because its separate font license has not been established. The implementation must use the engine default font or bring an independently cleared font.

No upstream script, scene, project cache, or font is copied into `input/sp/`.
