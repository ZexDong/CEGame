# RougelikeTD Benchmark Input

This directory is the single canonical model-visible Input for the twelve-wave relic-defense task.

| Path | Purpose |
|---|---|
| `INITIAL_AGENT_PROMPT-en.md` | Required reading order and delivery contract |
| `GDD-en.md` | Fixed 12-wave player contract; Sections 6 and 12 are authoritative |
| `TOOLCHAIN-en.md` | Engine, input, material, dashboard, and verification contract |
| `BENCHMARK_MANIFEST.json` | Path and entry index |
| `sp/` | Answer-empty Godot starter with dashboard skeleton |
| `Assets/` | Material catalog, coverage, manifest, and contact sheet |
| `legal/` | Preserved license and attribution records |
| Shared documents | Common baseline, dashboard, and Godot tool guidance |

The package contains no answer implementation, reference trajectory, private scoring, or historical result. Only the copied `sp/` project is writable.
