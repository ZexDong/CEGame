# Tower Defense benchmark input

This is the single canonical model-visible input package. It contains the answer-free starter project, public task documents, licensed assets, the three shared Godot benchmark documents, and the read-only dashboard/self-check skeleton.

- `GDD-en.md` is the authoritative player-observable design and acceptance specification, including the final exact wave composition, Green Dino boss, enemy-to-tower attacks, tower HP, and 20-Gold repair operation.
- `MaterialMapping-en.md` maps every supplied bitmap and every procedural boss/projectile/health-bar/repair visual to its required gameplay identity.
