# Supplied Task Assets

This protected directory contains the supplied media slice listed in the root `ASSET_MANIFEST.json`. It was mechanically migrated for the pinned Unity version. Major groups include player and enemy sprites, audio, animation, materials, URP 2D settings, tile assets, and source prefabs.

Use `ASSET_CONTACT_SHEET.png`, `ASSET_CATALOG.md`, and `ASSET_CATALOG.json` for exact source paths, visible bounds, importer facts, and intended roles. Do not edit this protected directory. Put all project scripts and any derived sprites, materials, animations, prefabs, or Scenes under `Assets/NoirChallenge/**`.
