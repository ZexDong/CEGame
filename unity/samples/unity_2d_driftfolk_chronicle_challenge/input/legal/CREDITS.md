# Asset Credits and Asset Licenses

**This file is the effective license record for media assets in this project.**

The bundled upstream [LICENSE](LICENSE) (Apache-2.0) covers **source code only**. Art, audio, fonts, models, textures, and other media are governed by the licence recorded against them in the tables below, **and that record controls over Apache-2.0** for those files.

**Media not listed here is not licensed to you by Apache-2.0.** A missing record means *not yet documented*, not *free to reuse*. If a file cannot be given a row, the correct action is to remove the file rather than ship it undocumented.

## Redistribution tiers

| Tier | Meaning |
|---|---|
| `Yes` | Public-domain, CC0, MIT, or equivalent media. Commercial and non-commercial redistribution is allowed, with or without the project. |
| `Yes, attribution required` | Redistribution is allowed only while preserving the required credit and licence notice in a form the upstream licence accepts. |
| `With the project only` | First-party, procedurally generated, or generator-produced media. It may ship inside a working fork of this game, but may not be extracted, resold, or repackaged as an asset pack. |
| `No, permission required` | Purchased, commissioned, or otherwise restricted media. Remove or replace it before distributing a fork unless you hold permission, and keep its path in the publication exclusion list so it never enters a public snapshot. |

## Scope of this snapshot

The audio set contains **26 files**: 12 sound-effect `.wav` files, 7 music `.ogg` files and 7 ambience `.ogg` files. The modular visual kit below contains **45 runtime PNG components**, plus contact-sheet and palette images. No models or fonts are bundled.

The in-repo ledger is [`LICENSES.txt`](LICENSES.txt). It uses the same current project-relative paths and SHA-256 digests as [`ASSET_MANIFEST.json`](../ASSET_MANIFEST.json), with every shipped audio file listed exactly once in both records.

## What must a fork remove before redistributing?

**Nothing, if the fork stays a fork.** Every shipped file is either first-party generated output or generator output the project owns, so all of it may travel inside a working fork under the `With the project only` tier, provided this file and the `Powered by Stability AI` credit travel with it.

**Extraction is what is not allowed.** Do not lift the `.ogg` music and ambience beds, or the `.wav` cues, out of the project to resell or to publish as a sound pack. None of this audio is CC0, and none of it is offered here as standalone licensed media.

## Modular visual starter kit — Apache-2.0 derivative

The 45 runtime PNG components under `Assets/DriftfolkStarter/VisualKit/` are
deterministic standalone derivatives of the fixed upstream procedural `PixelArt.cs`
visual grammar and palette from `euuuuuuan/driftfolk-unity-public` commit
`3022c09bf53e396e90694be70b319c625a75931e`. They are covered by the project
Apache-2.0 `LICENSE`. Exact per-file paths, roles, dimensions, byte counts, and SHA-256
values are bound by `Assets/DriftfolkStarter/VisualKit/ASSET_CATALOG.json`; its binding,
contact-sheet hash, import-facts hash, and license files are recorded in
`ASSET_MANIFEST.json.visual_submanifest_binding`.

The contact sheet and palette are inventory documentation, not a final game screen. The
kit contains no final Scene, prefab, screen layout, gameplay code, or completed island
composition.
