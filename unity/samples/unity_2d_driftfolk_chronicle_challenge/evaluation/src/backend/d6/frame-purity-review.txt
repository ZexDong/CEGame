Use the exact raw PNG(s), immutable native player receipt and review-request
bindings. Do not edit, crop, replace, or improve an image. This review has the
same rules for every implementation and for service_commit and normal_input.

Check whether any host-injected temporary company identity is actually visible
in the captured pixels, including a clipped or wrapped GameCreateBenchmarkTemp
prefix. The request gives the exact temporary company. If visible, choose
host_identity_pollution. If uncertain, choose unresolved. Such a frame is an
observer failure requiring repair/review, not a candidate visual deduction and
never an automatic zero. Runtime text candidates are diagnostics, not proof
that the text is visible; use the actual full frame.

Reject an obvious foreign desktop, Editor chrome, host dialog or stale/other
process image as unresolved. Do not require a particular game layout, specific
decorative numbers, reference likeness, or successful/full gameplay. Poor game
art, missing features and ordinary candidate UI defects remain for evaluation;
this purity review must not silently become another quality score.

entry state only if the after image is recognizably initial gameplay rather than

to not_applicable; the public committed-state proof is independently checked.
