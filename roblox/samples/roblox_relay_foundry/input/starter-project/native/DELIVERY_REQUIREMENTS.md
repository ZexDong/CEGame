# Relay Foundry delivery requirements

Deliver:

- the complete `project/` Rojo source;
- `RelayFoundryCandidate.rbxlx` rebuilt from that source;
- `RUN_REPORT.txt` with PASS, FAIL, or NOT RUN and observed behavior for each public self-check;
- `DEVELOPMENT_TRACE.txt` listing meaningful implementation/test actions, modified files, and unresolved limitations.

Do not include Gold, private evaluator code, private results, historical candidates, generated caches, lock files, secrets, or machine-specific absolute runtime dependencies.
