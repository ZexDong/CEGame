# Supplied asset surface

This task intentionally ships no external media. Use Roblox Studio built-in instances and locally authored Luau:

- BaseParts and built-in materials for the complete navigable foundry;
- ProximityPrompt for all nearby `E` and `Q` interactions;
- default Roblox character and Humanoid for movement, health, death, and respawn;
- ScreenGui/BillboardGui/SurfaceGui and standard text/layout instances for HUD and labels;
- Lighting and built-in effects for presentation;
- CollectionService Tags and Attributes for the public protocol.

No marketplace asset ID, package, plugin, web download, or absolute runtime file path is required. External assets may not become a hidden dependency of the delivered game.
