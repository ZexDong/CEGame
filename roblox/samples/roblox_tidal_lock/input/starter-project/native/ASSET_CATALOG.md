# Asset catalog

| Asset path | Type | Required role |
|---|---|---|
| `TaskAssets/VISUAL_PALETTE.json` | JSON palette | Suggested colors/materials for canal structure, water, controls, hazards, success and HUD |
| `Starter/TidalLockStart.rbxlx` | Blank RBXLX | Engine-openable starting place; not finished gameplay or visual reference |
| `Starter/project/` | Rojo starter | Portable project mapping and public Schema module |

No external image, mesh, audio or package asset is supplied. All visible world geometry and HUD may be constructed with built-in Roblox primitives and standard UI objects. The palette guides style but does not prescribe absolute coordinates or hierarchy.
