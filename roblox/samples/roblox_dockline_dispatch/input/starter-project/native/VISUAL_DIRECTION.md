# Dockline Dispatch visual direction

Create a readable night-shift dock and warehouse using Roblox primitives. Use dark steel and concrete structure, cool blue ambient navigation, amber scanning/processing indicators, distinct A/B/C route colors, red danger/rejection, and green accepted/completed state. Packages, stations, diverters, bays, pallet slots, seal, safe waiting area, forklift hazard, and truck controls must be easy to distinguish.

The supplied palette and contact sheet are style ingredients, not a target screenshot or final layout. Coordinates, decoration, room orientation, and camera composition are not prescribed. Avoid overlapping prompts, debug geometry, placeholder labels, unreadable package identity, or HUD panels that obscure movement.
