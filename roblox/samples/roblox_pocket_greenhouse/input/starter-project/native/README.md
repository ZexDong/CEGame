# Pocket Greenhouse - Public Input

Supply only this directory to the development agent. Build a playable,
mouse-driven greenhouse management game from scratch using Roblox Studio.

Read in order:

1. PROMPT.txt: delivery and boundaries.
2. GDD.md: complete game rules.
3. COMMON_BASELINE.md: shared quality requirements.
4. DASHBOARD_SPEC.md: read-only Roblox state interface.
5. naming-tables.json: fixed dashboard names.
6. TOOLCHAIN.md: project and runtime requirements.
7. examples/: interface skeleton and self-check examples.

Requirements come from the GDD and Common Baseline, without hidden gameplay.
The dashboard reports state and cannot replace normal mouse interaction.
This input contains no scorer, weights, solutions, faulty variants, calibration
results, or historical candidate results.
